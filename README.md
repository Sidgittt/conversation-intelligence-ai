# Conversation Intelligence AI

An AI-powered application for analyzing WhatsApp conversations and generating structured conversation insights.

## Overview

Conversation Intelligence AI processes exported WhatsApp chat data and converts raw conversations into structured insights.

The application combines:

- WhatsApp chat parsing
- Conversation grouping
- AI-based conversation analysis
- Emotion analysis
- Topic detection
- Toxicity indicators
- Relationship/context analysis
- Conversation summaries
- Evidence-based analysis
- AI-assisted retrieval and question answering
- Interactive Streamlit dashboard
